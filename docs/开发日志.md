## 2026-06-01 第二次修复

### 问题：页面全白
**原因**：路由守卫逻辑 bug，所有页面默认需要登录，没 token 就跳登录页，登录页本身也需要登录，形成死循环
**修复**：修改 `router/index.js`，改为只有标记了 `meta: { auth: 'user' }` 的页面才需要登录

### 问题：Vite @ 别名不生效
**原因**：`'@': '/src'` 写法不正确
**修复**：改为 `path.resolve(__dirname, 'src')`

## 2026-06-01 第三次修复

### 问题：所有登录都失败
**原因**：
1. SQL 里的 BCrypt 密码哈希是随便写的，和 `123456` 不匹配
2. Store 里的登录方法没有 try-catch，后端没启动时直接报错

**修复**：
1. 创建 `DataInitializer.java`，后端启动时用正确的 BCrypt 哈希自动创建/更新测试账号
2. 三个 Store（user.js、shop.js、admin.js）都加了 try-catch，显示具体错误原因
3. SQL 去掉了错误的测试数据 INSERT，改为由后端自动初始化
4. 修复管理员下架图书 bug：`updateBookStatus` 传 null shopId 时的判断逻辑

## 2026-06-01 第四次修复

### 问题：商家访问前台会退出登录
**原因**：`api/index.js` 的响应拦截器遇到 401 时调用了 `localStorage.clear()`，清空了所有 token（包括商家的 shopToken）

**修复**：401 时只弹提示，不再清 localStorage

## 2026-06-01 第五次修复（架构 + 功能补全）

### 1. 架构问题：所有页面用原生 axios（20个文件）
**原因**：所有 Vue 页面直接 `import axios from 'axios'`，没有用 `api/index.js` 封装好的 request 实例，导致 token 自动注入、401 处理全部失效

**修复**：全部替换为 `import request from '@/api'`，`axios.get/post/put/delete` → `request.get/post/put/delete`

**涉及文件**：
- 用户端：Home、BookList、BookDetail、Cart、OrderConfirm、MyOrders、Address、MyReviews、Profile、Layout
- 商家端：Dashboard、Books、BookEdit、Orders、Reviews、ShopSetting
- 管理员端：Dashboard、Shops、Users、Books、Categories、Orders

**同时修复 api/index.js**：
- 去掉 `baseURL: '/api'`（避免 URL 重复 `/api/api/...`）

## 2026-06-01 第九次修复

### 问题：分类导航栏消失、首页图书不显示
**原因**：响应拦截器返回 `response.data`（已解包），但所有页面代码用 `res.data.code` 访问（多了一层 `.data`），导致条件永远为 false，数据取不到
**修复**：`api/index.js` 响应拦截器改为返回完整 `response` 对象，页面 `res.data.code` / `res.data.data` 正确匹配
